# Futuristic Calculator

A high-performance scientific calculator built with a futuristic, cyberpunk-inspired aesthetic. This project features a responsive glassmorphism design, smooth mode transitions between basic and advanced functionality, and robust mathematical expression evaluation.

## Features

- **Futuristic Interface**: Premium glassmorphism UI with ambient glow effects and custom typography.
- **Dynamic Modes**: Seamless transition between Basic and Advanced (Scientific) layouts.
- **Robust Math Engine**: Powered by Math.js for precise evaluation of complex expressions.
- **History Log**: Keeps track of recent calculations within the session.
- **Fully Responsive**: Optimized for desktop and mobile devices.
- **Keyboard Support**: Full support for physical numeric keypads and standard operators.

## Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Advanced animations, grid layouts, and glassmorphism effects.
- **JavaScript (ES6+)**: Core logic and UI state management.
- **Math.js**: Powerful mathematical expression parsing and evaluation.

## Getting Started

Simply open `index.html` in any modern web browser to start using the calculator.
